AREA-FIRST IMPLEMENTATION PLAN (AI-OPTIMIZED BRIEF)
===================================================

Purpose
-------
Unify all world “rooms” and “trails” under one `Area` model, compute map bounds dynamically, move spawn logic to Areas, and embed per-asset geometry as `AssetArea`. This plan summarizes invariants, data shapes, APIs, file touch-points, and acceptance tests so agents can execute tasks deterministically.

Guiding Rules (Do Not Violate)
------------------------------
1) Single world tree: `Area (root) -> Areas | Assets`. Assets cannot contain Assets. Assets can contain `AssetArea` *only* (no children Areas, no SpawnGroups).
2) Map bounds are computed at load from layer radii; never hardcode width/height/radius and never trust legacy JSON values.
3) Only `Area` owns `SpawnGroups`. Assets never spawn content.
4) Geometry comes in two modes: *Primitive* (circle/rect/trail) or *Polygon*. Use anchors: `center_center` for Areas, `bottom_center` for AssetAreas.
5) Depth is semantic: `depth=0` root map; immediate children `depth=1` (former “rooms/trails”). Children always have `child.depth = parent.depth + 1`.
6) Spacing & containment are checked at spawn-time; deterministic placement = seed per Area + stable ordering.
7) Dev-mode shows/edits the same Area model; no separate Map vs Room modes.

Core Types
----------
Area (ENGINE/utils/area.hpp)
- id: std::string (unique within map)
- tag: std::string (“Room”, “Trail”, “Custom”, “Map”, etc.)
- depth: int (0 for root)
- parent: Area* (nullable; root has nullptr)
- children_areas: std::vector<std::unique_ptr<Area>>
- children_assets: std::vector<std::unique_ptr<Asset>>
- geometry:
  - mode ∈ { circle, rect, trail, polygon }
  - params:
    * circle: radius
    * rect: width, height
    * trail: std::vector<SDL_FPoint> path_points, float width
    * polygon: std::vector<SDL_FPoint> points, anchor_mode ∈ { center_center }
- spacing: { min_same_type: float, min_global: float } (applies to direct siblings only)
- spawn_groups: std::vector<SpawnGroup>

Methods (non-exhaustive):
- SDL_FRect aabb() const
- bool contains_point(SDL_FPoint p) const
- bool contains_aabb(SDL_FRect r) const (approx ok)
- void set_depth_from_parent()
- double area_approx() const (for density calculations)

Asset (ENGINE/asset/Asset.hpp)
- parent_area: Area* (non-owning; set on attach)
- areas: std::vector<AssetArea>  // colliders/triggers/etc.

AssetArea (ENGINE/asset/Asset.hpp)
- id: std::string (“hitbox”, “trigger”, …)
- geometry:
  - mode ∈ { circle, rect, polygon }
  - params as per Area but coordinates are LOCAL to asset
  - anchor_mode = bottom_center (fixed)
Derived/world forms are computed from Asset transform each frame or when dirty.

SpawnGroup (ENGINE/utils/area.hpp or ENGINE/spawn/spawn_group.hpp)
- id: std::string
- candidates: std::vector<SpawnCandidate>
  - type ∈ { Area, Asset }
  - ref_id: std::string  // Area template id or asset type id
  - weight: double
- rules:
  - min_count: int (≥0)
  - max_count: int (≥min_count)
  - density_per_1000u2: double (optional; used if min/max omitted)
  - max_attempts: int (default 16)
  - allowed_depth_min/allowed_depth_max (optional)
  - override_spacing: optional { min_same_type, min_global }

Determinism
-----------
- Global seed from map file (or engine config).
- Per-Area RNG = hash(global_seed, area.id).
- Iterate spawn_groups in JSON order; within a group, pick candidate by normalized weights using the per-Area RNG.

Map Bounds (Root Area)
----------------------
- Compute at load from layer radii (pre-existing layer logic). Size = 2*(max_radius + outer_padding); center derived from engine convention.
- Instantiate root Area { id:"map_root", tag:"Map", depth:0, mode:circle|rect } with computed size, before any children/spawns.
- Deprecate/ignore legacy `map_radius`, `map_width`, `map_height` fields (log once).

Geometry & Anchors
------------------
- Areas default to `center_center` anchor.
- AssetAreas use `bottom_center` relative to the sprite’s origin (sprite bottom center = (0,0)).
- Trail generation expands a polyline to a corridor polygon (caps/joins allowed). Store canonical polygon for tests and AABB.

Spawn Placement & Spacing
-------------------------
- Candidate position sampling: rejection sampling inside parent Area polygon/AABB (point-in-polygon or conservative shrink by radius).
- Spacing checks against all existing siblings in the *same parent*:
  - same-type spacing: Areas vs Areas, Assets vs Assets
  - global spacing: against both types
- Overlap metric: center distance ≥ rA + rB + spacing; where rX comes from inscribed/bounds circle or AABB half-diagonal.
- Containment: if child is Area, ensure child.aabb() fits in parent (contains_aabb). If not required by design, allow overflow (but prefer containment for nested Areas).
- Failure handling: after `max_attempts`, skip instance; warn if below `min_count`.

JSON Schema (Authoring)
-----------------------
Top-Level
{
  "areas": [
    {
      "id": "map_root",
      "tag": "Map",
      "geometry": { "mode": "circle", "radius": 1500 },
      "spacing": { "min_same_type": 0, "min_global": 0 },
      "spawn_groups": [ ... ],
      "children": [ ... ]
    },
    // Optional templates (referenced by spawn candidates)
    { "id":"small_square_room","tag":"Room","geometry":{"mode":"rect","width":200,"height":200} }
  ],
  "assets": [
    { "id":"enemy_frog",
      "areas":[
        {"id":"hitbox","geometry":{"mode":"circle","radius":12},"anchor_mode":"bottom_center"}
      ]
    }
  ]
}

Area Entry
- id, tag, geometry, spacing (optional), spawn_groups (optional), children (optional: inline instances)
- children entries can be full definitions or { "ref": "template_id", "position": [x,y] }

SpawnGroup Entry
- id, rules, candidates[] (each { type, ref_id, weight })

Runtime Integration
-------------------
Rendering / Scene (ENGINE/render/scene_renderer.cpp)
- Iterate visible Areas & Assets; draw assets sorted by z/y as before.
- Dev overlay: draw root aabb; optional outlines for current edited Area.

Camera (ENGINE/render/camera.*)
- `set_world_bounds(SDL_FRect)` to clamp based on root Area aabb.
- Fit-to-map uses root Area aabb.

Light Map (ENGINE/render/light_map.*)
- Initialize using world bounds; clip blits to bounds.

Assets Manager / Queries
------------------------
- Replace room-based collections with Area traversals.
- Provide helpers:
  - gather_depth1_areas(root) -> vector<Area*>
  - for_each_asset(root, fn)  // DFS traversal
- Player/current area detection: find smallest Area (by depth) whose polygon contains player; fall back to nearest depth1 if needed.

Editor (Dev Mode)
-----------------
- Single “Area Editor”. No map/room mode switches.
- Navigation: click to select; double-click (or ‘Enter’) to drill down; “Back to Parent” button.
- Panels:
  - Area Properties: id, tag, depth (read-only), geometry (mode + fields), spacing, spawn_groups (list + candidates + rules)
  - Asset Properties: type, transforms; AssetAreas editor (add/remove; edit shapes in local space)
- Save/Load: writes new schema; legacy fields are ignored (log once).

Migration & Legacy
------------------
- Remove Room/Trail classes and their containers (rooms_, all_rooms_). Replace with Area tree.
- Where old logic asked for “rooms”, provide `gather_depth1_areas(root)` or move to DFS traversal.
- AssetSpawnPlanner: delete; convert its data into Area.spawn_groups.
- Keep a one-time converter (optional) to build Areas from old map files; do not keep mixed runtime paths.

Minimal Public APIs (Suggested)
-------------------------------
ENGINE/utils/map_area.hpp (optional helper)
- struct MapArea { SDL_FPoint center; SDL_FPoint size; SDL_FRect aabb() const; }
- MapArea compute_map_area_from_layers(const std::vector<float>& radii, float padding);
- MapArea compute_map_area_from_assets(const std::vector<const Asset*>& roots, float padding);

ENGINE/core/AssetsManager.hpp
- const Area* get_root_area() const; Area* get_root_area();
- const MapArea& get_map_area() const;  // if using MapArea helper

ENGINE/render/camera.hpp
- void set_world_bounds(const SDL_FRect& bounds);

Hot-Path Notes
--------------
- Use out-parameter overloads to avoid per-frame allocations for neighbor queries (reuse buffers).
- Cache AABBs for Areas and AssetAreas; recompute only on edits/moves.
- Prefer SDL_RenderCopyF for sub-pixel smoothness; keep camera/asset transforms in float.

Acceptance Checklist (Per Task Group)
-------------------------------------
Map Bounds
- Root Area exists at depth 0 with computed size; camera clamps to its bounds; dev overlay shows correct aabb.

Area/Hierarchy
- All top-level world regions are Areas at depth 1 with proper tags; no legacy Rooms/Trails remain.

Spawn
- Given fixed seed, identical map produces identical placements; failure to place meets min_count checks and logs clean warnings.

Editor
- Drill-down and return work across multiple depths; geometry edits persist; spawn_groups can be added/edited/removed; AssetAreas editable in local space.

Runtime
- No hardcoded map sizes; render, lighting, and culling operate from Area tree; AI/player area checks succeed.

Performance
- Spawning completes under expected time for typical content sizes; per-frame traversal cost unchanged or improved vs legacy.
